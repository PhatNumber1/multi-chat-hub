**Test build.** Twitch sign-in and the automatic OBS connection work inside a real OBS. Kick chat was tested live. YouTube and TikTok have not been tried with a real key yet.

1. Close OBS.
2. Download and run the `.exe` below and follow the steps.
3. Open OBS and tick **Docks > Multi Chat Hub** if it is not showing.

The installer is not signed, so Windows may show a warning. It was built by GitHub from the source in this repository.

New: the installer can connect the dock to OBS by itself, with no password to copy.
